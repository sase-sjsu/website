# SASE SJSU Website

The official website for the **Society of Asian Scientists & Engineers (SASE)** chapter at **San José State University**. Built with [Next.js](https://nextjs.org), React, and Tailwind CSS.

## About the Project

This website serves as the online presence for SJSU's SASE chapter, featuring:

- **Home** — Landing page with an image carousel, upcoming events, programs overview, and social links
- **About Us** — President's message, mission and values, executive board, and FAQs
- **Events** — Event calendar for chapter activities
- **Programs** — Information on Kickstarter, Mentorship, and Internship programs
- **Sponsorship** — Details for potential sponsors

## Tech Stack

- [Next.js 15](https://nextjs.org) (App Router, Turbopack)
- [React 19](https://react.dev)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS 4](https://tailwindcss.com)
- [React Aria Components](https://react-spectrum.adobe.com/react-aria/)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.

### Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start development server with Turbopack |
| `npm run build` | Create a production build |
| `npm start` | Run the production server |
| `npm run lint` | Run ESLint |
